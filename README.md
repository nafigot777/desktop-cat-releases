# LexiBuddy 🐾

> 当年养电子宠物的那群人又回来了：这一次，你背过的每个单词都能养活桌面上的小伙伴。

LexiBuddy 是一款运行在 macOS 桌面上的轻量像素伙伴与语言学习应用。

NINI 会住在屏幕角落，散步、睡觉、伸懒腰，也会偶尔递来一张十几秒就能完成的学习纸条。答对英语、日语或韩语题目可以获得口粮；完成每日目标，就是今天有没有把伙伴喂饱。

## 下载最新版

前往 **[Releases 下载 LexiBuddy 最新版本](https://github.com/nafigot777/lexibuddy-releases/releases/latest)**。

请选择名为 `LexiBuddy-vX.Y.Z-Universal.zip` 的安装包。Universal 版本同时支持：

- Apple Silicon：M1、M2、M3、M4 等
- Intel 芯片 Mac
- macOS 13 或更高版本

## 安装方法

1. 下载 Universal ZIP 并双击解压。
2. 将 `LexiBuddy.app` 拖入“应用程序”文件夹。
3. 双击打开 LexiBuddy。
4. 选择今天的伙伴和学习目标，点击“开始上班”。

### 如果 macOS 提示无法验证开发者

当前测试版暂未进行 Apple 公证。第一次打开时，请进入：

**系统设置 → 隐私与安全性 → 仍要打开**

也可以在 Finder 中右键 `LexiBuddy.app`，选择“打开”，再确认一次。

请只从本仓库的 Releases 页面下载安装包。

## 现在可以做什么

- 🐾 低打扰桌面陪伴：固定、自由走动、睡觉、伸懒腰和互动
- 📚 英语、日语、韩语词书与三种轻量题型
- 🍪 答题赚口粮，完成每日目标并记录学习日历
- 🔎 中文找外文、外文找中文，以及完整离线查词台
- 🎨 创建自己的桌面伙伴，上传 GIF、修改食物名称
- 💛 为自定义伙伴新增“摸摸头”“摸胡须”等独立互动动作
- 🧭 首次使用操作向导与可缩放的设置窗口

## 数据与隐私

LexiBuddy 可以离线使用，不要求注册账号。学习记录、口粮、自定义伙伴和 GIF 都保存在每位用户自己的 Mac 上，不会随安装包共享给其他人。

公开下载包只包含运行应用需要的只读词库，不包含内部 Workbench、词库母库、API 密钥或作者的个人学习记录。

## 自动更新

LexiBuddy 使用 GitHub Releases 与 Sparkle 提供版本更新。安装本版本后，后续可以从菜单栏选择 **“检查更新…”**；发布新版本时，应用也会按设置自动检查。

替换或更新 App 不会清除保存在本机的学习进度、自定义伙伴和口粮。
