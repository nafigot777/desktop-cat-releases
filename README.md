# Desktop Cat 🐾

> 当年养电子宠物的那群人又回来了！这次，背过的每个单词都是小猫的口粮。

Desktop Cat 是一款运行在 macOS 桌面上的轻量像素宠物 + 语言学习产品。

Nini 会安静地住在屏幕角落，散步、睡觉、伸懒腰、找你要饭饭。英语、日语和韩语词汇会被拆成十几秒可以完成的学习小纸条；每答对一道题，就能赚到一份口粮。

## 下载最新版

请前往右侧的 **Releases**，或点击：

**[下载 Desktop Cat 最新版本](https://github.com/nafigot777/desktop-cat-releases/releases/latest)**

目前提供 Universal 版本，同时支持：

- Apple Silicon：M1、M2、M3、M4 等
- Intel 芯片 Mac
- macOS 13 或更高版本

## 安装方法

1. 在 Releases 页面下载 `DesktopCatCompanion-Final-Universal.zip`。
2. 双击 ZIP 解压。
3. 将 `DesktopCatCompanion.app` 拖进“应用程序”文件夹。
4. 双击打开。

### 如果 macOS 提示无法验证开发者

当前测试版本暂未进行苹果公证。请进入：

**系统设置 → 隐私与安全性 → 仍要打开**

也可以在 Finder 中右键 App，选择“打开”，再确认一次。

## 产品特点

- 🐱 低打扰像素桌宠
- 📚 英语、日语、韩语词书
- 📝 三种轻量题型
- 🍪 答对题目赚口粮并投喂 Nini
- 📅 每日目标与学习记录
- 🔎 本地查词
- 🎨 支持自定义伙伴及 GIF 动作
- 🔒 学习记录和自定义伙伴保存在用户自己的 Mac

## 数据与隐私

Desktop Cat 可以离线使用，不需要注册账号。学习进度、口粮和自定义伙伴保存在每位用户自己的 Mac 上，安装包不会携带作者的个人学习记录。

## 更新方式

当前版本通过 GitHub Releases 发布更新。发布新版后，请在本仓库下载最新 ZIP 并替换旧 App；用户本地的学习数据不会因为替换 App 而消失。

自动更新功能将在后续版本加入。
